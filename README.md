# הדשבורד של שחר: אפליקציה

הדשבורד המלא, כאפליקציה שעובדת גם בלי רשת.

- **הנתונים:** כל עמוד שומר את הנתונים שלו בקובץ MEMORY.md של התחום שלו ב-Google Drive, בבלוק `נתוני הדשבורד` בסוף הקובץ. שאר הטקסט בקובץ לא משתנה.
  - משימות: `מקצועי/לו״ז ומשימות`
  - חובות: `מקצועי/חובות והלוואות`
  - פיננסים: `מקצועי/פיננסים`
  - ספורט ופנאי: `פנאי/ספורט בישול טיולים וספרים`
- **בטלפון:** עותק אופליין ותור שינויים. כשיש רשת כל קובץ מסתנכרן בנפרד.
- **Claude והסוכנים:** קוראים וכותבים לאותו בלוק (ההוראות בהמשך).

## אחרי העדכון

1. להעלות ל-GitHub (GitHub Desktop → Commit → Push).
2. באפליקציה: לחיצה על התג בפינה ← **התנתק** ← **התחבר**. ההרשאה השתנתה ל-Drive מלא. Google תציג אזהרה שהאפליקציה לא מאומתת: **Advanced ← Go to … (unsafe)**. זו האפליקציה שלך.

## הוראות ל-Claude ולסוכנים: עדכון נתוני הדשבורד

- **לקרוא** את MEMORY.md עם `download_file_content` (תוכן גולמי). `read_file_content` מוסיף escape שהורס את ה-JSON.
- **הבלוק:** ```` ```json dashboard-data ```` . בכל פריט, `_f` שומר מתי כל שדה נכתב לאחרונה, בזמן ISO. השינוי החדש יותר מנצח, שדה מול שדה.
- **לשנות שדה:** לעדכן את הערך ואת `_f.<שדה>` לזמן הנוכחי (ISO, UTC).
- **להוסיף פריט:** `id` חדש וייחודי, כל השדות, `"deleted": false`, ו-`_f` לכל שדה.
- **למחוק:** `"deleted": true` ולעדכן את `_f.deleted`. לא מוחקים שורות מהרשימה.
- **נתוני פיננסים** (`fields`, `id` כמו `finance.shortMedium`): להחליף את `value` ולעדכן את `_f.value`.
- **לשמור:** קובץ חדש באותה תיקייה עם **כל** הטקסט ועם הבלוק, ואז להעביר את הישן לפח. האפליקציה תמיד לוקחת את הקובץ החדש ביותר, ומחזירה בעצמה שינויים מהטלפון אם הם נדרסו.
- **אסור** לשמור את הקובץ בלי הבלוק. האפליקציה תעצור ולא תכתוב.
