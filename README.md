# הדשבורד של שחר: אפליקציה

אותו דשבורד בדיוק, אבל רץ כאפליקציה שעובדת גם בלי רשת.

- **הנתונים:** קובץ אחד ב-Google Drive, `dashboard-data.json`. זה מקור האמת היחיד.
- **בטלפון:** עותק אופליין ותור שינויים. כשיש רשת הם מסתנכרנים עם ה-Drive.
- **Claude:** קורא ומעדכן את אותו קובץ ב-Drive.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מעטפת האפליקציה: מסך פתיחה, כפתור סנכרון ותחילת הטעינה |
| `legacy.js` + `styles.css` | המסכים של הדשבורד המקורי, כמעט בלי שינוי (נוצרים ע"י `tools/port_legacy.py`) |
| `boot.js` | מחבר בין המסכים למנוע הסנכרון: כל שינוי הופך ל-ops, ועדכונים נכנסים מה-Drive |
| `model.js` | ממיר בין הדשבורד לקובץ ב-Drive |
| `sync.js` | מנוע הסנכרון (נבדק בגרסת הניסוי) |
| `store.js` / `drive.js` / `auth.js` | מסד מקומי / Google Drive / התחברות |
| `calendar.js` | חיבור ישיר ל-Google Calendar, במקום החיבור דרך Claude |
| `sw.js` | עבודה בלי רשת (קוד ופונטים בלבד) |

**אין בקוד שום מידע אישי.** גם רשימת היומנים עברה לקובץ הנתונים.

## הגדרה

1. **Google Cloud → Library:** חפש **Google Calendar API** ולחץ **Enable** (בנוסף ל-Drive API שכבר מופעל).
2. **GitHub, ב-repository `dashboard`:** העלה את כל הקבצים מה-ZIP, כולל התיקיות `tools` ו-`tests`.
   **ב-ZIP אין `config.js` בכוונה.** הקובץ שכבר יש לך ב-GitHub, עם ה-Client ID, נשאר כמו שהוא.
   את `app.js` הישן מגרסת הניסוי אפשר למחוק.
3. **התחברות מחדש:** פתח את האתר, לחץ על התג הקטן בפינה ← **התנתק** ← **התחבר**. צריך לאשר גם הרשאת יומן (קריאה בלבד).

## ייבוא חד-פעמי

פעם אחת בלבד, במחשב:

1. פתח את האתר והתחבר. תראה "אין בו עדיין נתונים".
2. לחץ **בחר קובץ ייבוא** ובחר את `dashboard-import.json`, הקובץ שנשלח בנפרד.
3. **אל תעלה את קובץ הייבוא ל-GitHub.** יש בו את כל המידע האישי. אחרי הייבוא אפשר למחוק אותו.

הייבוא לא יפעל אם כבר יש נתונים ב-Drive, כך שאי אפשר לדרוס בטעות.
