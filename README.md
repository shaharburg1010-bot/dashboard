# הדשבורד של שחר: אפליקציה

הדשבורד המלא, כאפליקציה שעובדת גם בלי רשת.

- **הנתונים:** כל עמוד שומר את הנתונים שלו בקובץ MEMORY.md של התחום שלו ב-Google Drive, בבלוק `נתוני הדשבורד` בסוף הקובץ. שאר הטקסט בקובץ לא משתנה.
  - משימות: `מקצועי/לו״ז ומשימות`
  - חובות: `מקצועי/חובות והלוואות`
  - פיננסים: `מקצועי/פיננסים`
  - ספורט ופנאי: `פנאי/ספורט בישול טיולים וספרים`
- **בטלפון:** עותק אופליין ותור שינויים. כשיש רשת כל קובץ מסתנכרן בנפרד.
- **Claude והסוכנים:** קוראים וכותבים לאותו בלוק (ההוראות בהמשך).

## אחרי העדכון

1. להעלות ל-GitHub (GitHub Desktop → Commit → Push).
2. באפליקציה: לחיצה על התג בפינה ← **התנתק** ← **התחבר**. ההרשאה השתנתה ל-Drive מלא. Google תציג אזהרה שהאפליקציה לא מאומתת: **Advanced ← Go to … (unsafe)**. זו האפליקציה שלך.

## הוראות ל-Claude ולסוכנים: עדכון נתוני הדשבורד

**לא כותבים ישירות לבלוק.** יוצרים בתיקייה של התחום קובץ עדכון קטן, והאפליקציה מכניסה אותו לבלוק בסנכרון הבא ומעבירה את הקובץ לפח.

- **שם הקובץ:** `dashboard-inbox <תאריך-שעה> <מי>.json`, בתיקייה של התחום (התיקיות ב-`config.js`). יוצרים עם `create_file`: `contentMimeType="application/json"`, `disableConversionToGoogleType=true`.
- **תוכן:** `{"by": "<שם הסוכן>", "changes": [ ... ]}`. סוגי השינויים:
  - `{"set": "finance.shortMedium.analystGemel.value", "value": 179500}`: ערך בנתיב.
  - `{"set": "finance.shortMedium.ibkr.holdings[QQQ].price", "value": 704.4}`: `[x]` בוחר פריט ברשימה לפי id או ticker, או לפי מספר אינדקס.
  - `{"add": "tasks", "item": {"cat": "כללי", "text": "...", "urgent": false}}`: id נוצר אוטומטית.
  - `{"update": "tasks", "id": "t_123", "fields": {"urgent": true}}`
  - `{"remove": "debts", "id": "d4"}`
- **לקרוא נתונים:** הבלוק `נתוני הדשבורד` שבסוף MEMORY.md (`read_file_content` מספיק לקריאה). אם יש בתיקייה קובצי `dashboard-inbox` שעוד לא עובדו, השינויים שבהם עוד לא נכנסו לבלוק.
- **כשמשכתבים MEMORY.md** (עדכון טקסט רגיל): מעתיקים את הבלוק כמו שהוא, אף פעם לא משמיטים אותו. גם אם ההעתקה מוסיפה escape (`\_`, `\[`), האפליקציה יודעת לתקן את זה.

## מחירים כל שעה (בלי AI)

- `.github/workflows/prices.yml` מריץ כל שעה את `tools/fetch-prices.mjs` ב-GitHub. הסקריפט מביא מחירים מ-Yahoo (גיבוי: Stooq) ומ-TASE (מאיה, גיבוי: Yahoo), ואת שער הדולר. התוצאה נשמרת כ-`prices.json` בענף `prices`.
- הניירות ברשימה נקבעים ב-`prices.config.json`. מוסיפים שם נייר חדש שנקנה. ה-repo ציבורי, כך שרשימת הניירות גלויה, אבל הכמויות והסכומים לא.
- **האפליקציה:** בכל פתיחה, ואחר כך פעם בשעה כל עוד היא פתוחה, היא קוראת את הקובץ, מחשבת את השווי, את "מאז קנייה" (לפי מחיר העלות בשקלים שנגזר מנתוני הבנק) ואת הגרף, וכותבת לדרייב.
- **הרצה ידנית:** GitHub ← Actions ← prices ← Run workflow. מה שנכשל מופיע ב-`errors` שבקובץ, וגם ביומן הסנכרון באפליקציה.

## ניתוח הוצאות חודשי

שחר שולח ל-Claude תדפיסי בנק ואשראי. Claude מסווג, מנתח וכותב ל-`finance.spending` דרך קובץ inbox בתיקיית פיננסים. נשמרים רק סיכומים לפי קטגוריה, בלי עסקאות ובלי מספרי כרטיס.
```
{"set":"finance.spending","value":{"asOf":"DD.MM.YYYY","source":"...",
 "months":[{"id":"2026-10","label":"אוק׳","total":9200,"byCat":{"סופר":1950,"מסעדות ומשלוחים":2100}}],
 "insights":[{"title":"...","text":"...","saving":550}],
 "trends":[{"text":"...","dir":"up|down|flat"}]}}
```
`months` ממוינים מהישן לחדש, וכל חודש חדש נוסף לרשימה הקיימת. כדי שההשוואה לממוצע תהיה עקבית, משתמשים באותם שמות קטגוריות בכל חודש.
